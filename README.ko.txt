3. Homey에 앱을 설치하세요. 
4. Homey에서 버튼 + 앱 설정/구성 페이지를 엽니다.
5. Button+ 구성 업데이트 허용이 선택되어 있는지 확인하십시오.

구성에는 버튼 표시줄과 디스플레이의 두 가지 유형이 있으며 각각 현재 20개의 슬롯이 있습니다.
버튼 표시줄 구성은 첫 번째 드롭 목록에 버튼 표시줄 구성이 표시될 때 표시���며 디스플레이 구성은 드롭 목록을 디스플레이 구성으로 변경하여 표시됩니다.

버튼바 구성 설정:

1. 첫 번째 드롭다운 목록에서 버튼바 구성을 선택합니다.
2. 편집할 구성 번호를 선택합니다(나중에 구성을 Button+ 패널에 할당할 수 있음).
3. 왼쪽 버튼 표시줄 아래에는 Button+ 버튼 표시줄 왼쪽에 있는 버튼에 대한 옵션이 있습니다.
4. 드롭 목록에서 제어하려는 Homey 장치를 선택합니다. (패널은 부울 기능만 지원하지만 목록 필터링은 아직 구현 중입니다.)
5. 드롭 목록에서 기능을 선택합니다.
6. 상단 라벨을 입력합니다(선택 사항). 이는 버튼 표시에 녹색으로 표시됩니다.
7. 라벨을 입력합니다. 이는 상단 텍스트 바로 아래 버튼 표시에 흰색으로 더 큰 글꼴로 표시됩니다.
8. 오른쪽 버튼 모음에 대해 단계를 반복합니다.
9. 구성 저장 버튼을 클릭합니다. 창을 저장하고 닫는 것을 잊어버린 경우 프롬프트를 추가하는 것이 아직 남아 있습니다.

디스플레이 구성 설정:

1. 첫 번째 드롭다운 목록에서 디스플레이 구성을 선택합니다.
2. 편집할 구성 번호를 선택합니다(나중에 구성을 Button+ 디스플레이에 할당할 수 있음).
3. 새 표시 항목을 클릭합니다.
4. 장치 또는 "변수"를 선택하십시오.
5. 기능 또는 변수를 선택합니다.
6. 필요한 경우 라벨을 편집합니다.
7. 필요한 경우 단위를 편집합니다. (이것은 단지 텍스트일 뿐이며 디스플레이에 전송되는 값을 변경하지 않습니다.)
8. X 및 Y 위치를 입력합니다. 이는 디스플레이 너비/높이의 백분율입니다.
9. 너비를 입력합니다. 이는 디스플레이 너비의 백분율입니다.
10. 반올림 값을 입력합니다. 0 = 정수(정수), 1은 소수점 이하 1자리 등입니다.
11. 목록에서 글꼴 크기를 선택합니다.
12. 필요에 따라 더 많은 표시 항목을 추가합니다.
13. 구성 저장을 클릭합니다.

Homey에 장치 추가:

1. Homey에서 새 장치 옵션을 선택합니다.
2. 버튼 버튼바를 선택하세요.
3. 연결을 클릭하세요.
4. 그러면 목록에 있는 장치가 표시되므로 해당 장치를 선택하고 계속 진행하세요. (앱은 현재 일반 설정에 있는 이름을 사용하여 버튼 표시줄을 식별합니다.) 버튼 +가 발견되지 않으면 수동 옵션을 선택하고 IP 주소를 입력하여 수동으로 추가할 수 있습니다.
5. 해당 장치가 Homey에 추가됩니다.

Homey 장치 사용:

1. Homey에서 장치를 엽니다.
2. 두 번째 탭을 열어 디스플레이와 각 커넥터의 구성 목록을 확인합니다.
3. 상단 드롭 목록에서 디스플레이 또는 커넥터 번호를 선택합니다. (Homey는 현재 드롭 목록 위에 구성 목록을 표시하므로 원하는 것을 선택하는 것이 어려울 수 있습니다.)
4. 디스플레이/버튼 막대 커넥터에 적용할 구성 번호를 선택합니다.
5. 구성이 시뮬레이터에 업로드되지만 적용하려면 시뮬레이터를 새로 고쳐야 합니다. 가상 ID 오른쪽에 페이지를 새로 ��치는 버튼이 있습니다.
6. 이제 버튼 표시줄에 표시된 구성에서 선택한 정보를 볼 수 있습니다.
7. 미니 디스플레이의 버튼을 클릭하여 Homey의 기능을 전환할 수 있습니다.
