Button +

Превратите свою систему Homey в более умный и более аккуратный центр управления для тех вещей, которыми вы пользуетесь каждый день.

Button + позволяет легко создавать пользовательские физические панели управления, которые ощущаются как премиальная smart home панель, а не как беспорядочный набор переключателей и страниц. С панелью Button + вы можете собрать в одном месте те элементы управления, которыми действительно пользуетесь, видеть состояние в реальном времени с одного взгляда и сделать дом более продуманным и интуитивным.

Почему Button + того стоит

1. Управление вашими самыми важными устройствами и сценами одним нажатием.
2. Быстрая визуальная обратная связь с пользовательскими метками, текстом состояния и значениями дисплея в реальном времени.
3. Более аккуратный настенный smart home интерфейс без необходимости копаться в меню.
4. Гибкие макеты для кнопок, дисплеев и сгруппированных панелей.
5. Более быстрое ежедневное использование для сценариев освещения, климата, безопасности и медиа.
6. Современный настраиваемый внешний вид, который вписывается в ваш дом и аппаратную конфигурацию.

Быстрая настройка

1. Установите приложение на ваш Homey.
2. Откройте в Homey страницу Button + App settings / Configuration.

В приложении есть три основные области настройки.

1. Button bar configurations.
2. Display configurations.
3. Group configurations.

Каждая область конфигурации содержит набор слотов для построения макетов панели. Конфигурации button bar используются для кнопок управления, конфигурации display используются для дисплея панели, а конфигурации групп позволяют объединить всё это в полную конфигурацию панели Button +.

Настройка button bar configurations

1. Выберите Button bar Configurations в первом выпадающем списке.
2. Выберите номер конфигурации для редактирования. Позже этот номер можно назначить панели Button+.
3. В разделе Left button bar находятся параметры кнопки с левой стороны Button+ button bar.
4. Выберите в выпадающем списке устройство Homey, которым хотите управлять. Панели поддерживают boolean capabilities, хотя фильтрация всё ещё улучшается.
5. Выберите capability в выпадающем списке.
6. При желании введите Top Label. Он отображается зелёным цветом на дисплее кнопки.
7. Введите Label. Он отображается белым цветом и более крупным шрифтом на дисплее кнопки сразу под Top Text.
8. Повторите шаги для Right button bar.
9. Нажмите кнопку Save Configurations.

Настройка display configurations

1. Выберите Display Configurations в первом выпадающем списке.
2. Выберите номер конфигурации для редактирования. Позже его можно назначить дисплею Button+.
3. Нажмите New Display Item.
4. Выберите Device.
5. Выберите Capability.
6. При необходимости измените Label.
7. При необходимости измените Units. Это только текст и он не меняет значения, отправляемые на дисплей.
8. Введите позиции X и Y. Это проценты от ширины и высоты дисплея.
9. Введите ширину. Это также процент от ширины дисплея.
10. Введите значение Rounding. 0 означает целые числа, 1 означает 1 знак после запятой и так далее.
11. Выберите Font Size из списка.
12. При необходимости добавьте больше элементов дисплея.
13. Нажмите Save Configurations.

Настройка групп

Группы это самый простой способ определить полную физическую панель Button +. Группа представляет собой один завершённый макет панели и может объединять:

1. одну конфигурацию дисплея.
2. одну или несколько конфигураций button bar или connector.
3. пользовательское имя для панели.

Чтобы настроить группу:

1. Откройте вкладку Group Configurations в настройках приложения.
2. Выберите существующую группу или нажмите кнопку +, чтобы создать новую.
3. Дайте группе имя, например Панель гостиной или Панель главного коридора.
4. Выберите конфигурацию дисплея, которую нужно назначить этой группе.
5. Назначьте группе одну или несколько конфигураций connector или button.
6. Используйте область предварительного просмотра, чтобы проверить полный макет панели перед сохранением.
7. Дублируйте или удаляйте группы по мере необходимости, если вам нужны несколько макетов панели.

Это полезно, если вы хотите разные физические панели в разных комнатах или для разных задач, повторно используя одни и те же заготовки дисплея и кнопок.

Добавление устройства в Homey

1. Выберите в Homey опцию New Device.
2. Выберите Button button bar.
3. Нажмите Connect.
4. После этого вы должны увидеть устройство в списке. Выберите его и продолжайте. Сейчас приложение использует Name из General settings для идентификации button bar. Если Button + не найден, можно попробовать добавить его вручную, выбрав опцию Manual и введя IP адрес.
5. Устройство будет добавлено в Homey.

Использование устройства Homey

1. Откройте устройство в Homey.
2. Откройте вторую вкладку, чтобы просмотреть список конфигураций для дисплея и каждого connector.
3. Выберите Display или номер Connector из верхнего выпадающего списка. Сейчас Homey рисует список Configuration поверх выпадающего списка, поэтому выбрать нужный элемент может быть неудобно.
4. Выберите номер Configuration, который нужно применить к Display или button bar connector.
5. Конфигурация загружается в симулятор, но вам нужно обновить симулятор, чтобы она вступила в силу. Справа от Virtual Id есть кнопка для обновления страницы.
6. Теперь вы должны увидеть на button bar информацию, выбранную в конфигурации.
7. Вы можете нажимать кнопки на mini displays, чтобы переключать capability в Homey.

В приложении есть встроенный MQTT broker, поэтому для этого ничего настраивать не нужно. Однако на странице настроек приложения можно добавить один или несколько внешних MQTT brokers.
