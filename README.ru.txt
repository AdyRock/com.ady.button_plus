Кнопка управления + панели

Приложение поддерживает аппаратное обеспечение «Кнопка +».

Чтобы настроить приложение:

3. Установите приложение на свой Homey.
4. Откройте страницу настроек / конфигурации «Кнопка + приложение» в Homey.
5. Убедитесь, что установлен флажок Разрешить обновление конфигурации Button+.

Существует два типа конфигураций: панель кнопок и дисплей, каждая из которых в настоящее время имеет 20 слотов.
Конфигурации панели кнопок отображаются, когда в первом раскрывающемся списке отображаются конфигурации панели кнопок, а конфигурации дисплея отображаются путем изменения раскрывающегося списка на «Конфигурации дисплея».

Настройка конфигурации панели кнопок:

1. Выберите конфигурации панели кнопок из первого выпадающего списка.
2. Выберите номер конфигурации для редактирования (позже мы можем назначить любую конфигурацию панелям Button+).
3. В разделе «Левая панель кнопок» находятся параметры кнопки в левой части панели кнопок Button+.
4. Выберите устройство Homey, которым вы хотите управлять, из раскрывающегося списка (панели поддерживают только логические значения, но фильтрация списков еще не реализована)
5. Выберите возможность из раскрывающегося списка.
6. Введите верхнюю метку (необязательно). Это отображается зеленым цветом на дисплее кнопок.
7. Введите метку. Это показано белым и более крупным шрифтом на дисплее кнопок, чуть ниже верхнего текста.
8. Повторите шаги для правой панели кнопок.
9. Нажмите кнопку «Сохранить конфигурации». Осталось добавить подсказку, если вы забудете сохранить и закрыть окно.

Настройка конфигураций отображения:

1. Выберите «Конфигурации отображения» из первого раскрывающегося списка.
2. Выберите номер конфигурации для редактирования (позже мы можем назначить любую конфигурацию кнопке + дисплею).
3. Нажмите «Новый отображаемый элемент».
4. Выберите устройство или «переменную».
5. Выберите воз��ожность или переменную.
6. При необходимости отредактируйте метку.
7. При необходимости отредактируйте единицы измерения. (это только текст и не меняет значений, отправляемых на дисплей).
8. Введите позиции X и Y. Это процент ширины/высоты дисплея.
9. Введите ширину. Опять же, это процент от ширины д��сплея.
10. Введите значение округления. 0 = целые числа (целые), 1 – 1 десятичный знак и т. д.
11. Выберите размер шрифта из списка.
12. При необходимости добавьте дополнительные элементы отображения.
13. Нажмите «Сохранить конфигурации».

Добавление устройства в Homey:

1. Выберите параметр «Новое устройство» в Homey.
2. Выберите панель кнопок.
3. Нажмите «Подключиться».
4. После этого вы должны увидеть устройство в списке, поэтому выберите его и продолжайте. (В настоящее время приложение использует имя, найденное в общих настройках, для идентификации панели кнопок). Если кнопка + не найдена, вы можете попробовать добавить ее вручную, выбрав опцию «Вручную» и введя IP-адрес.
5. Устройство будет добавлено в Homey.

Использование устройства Homey:

1. Откройте устройство в Homey.
2. Откройте вторую вкладку, чтобы просмотреть список конфигураций дисплея и каждого разъема.
3. Выберите номер дисплея или разъема из верхнего раскрывающегося списка (в настоящее время Homey отображает список конфигурации поверх раскрывающегося списка, поэтому выбрать то, что вы хотите, может быть затруднительно).
4. Выберите номер конфигурации, который будет применен к разъему дисплея/панели кнопок.
5. Конфигурация загружена в симулятор, но вам необходимо обновить симулятор, чтобы изменения вступили в силу. Справа от виртуального идентификатора есть кнопка для обновления страницы.
6. Теперь вы должны увидеть информацию, которую вы выбрали в конфигурации, отображаемой на панели кнопок.
7. Вы можете нажимать кнопки на мини-дисплеях, чтобы переключать функции Homey.

Приложение имеет встроенный брокер MQTT, поэтому для этого не потребуется никакой настройки. Однако на странице настроек приложения можно добавить одного или нескольких внешних брокеров MQTT.
